# Map / Stage assets

Folder untuk menyimpan gambar map atau stage Tekken 8. Muat naik imej berlesen ke sini seperti `yakushima.webp`, `arena.webp`, kemudian tambah nama stage dan laluan fail dalam `catalog.json`.

Setiap perlawanan mempunyai tiga slot map/stage berasingan. Gambar juga boleh ditambah melalui URL HTTPS di popup Admin.

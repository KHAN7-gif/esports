# Character assets

Folder untuk gambar watak Tekken 8. Simpan gambar sebagai fail PNG/WebP jika mempunyai hak penggunaan, contohnya `jun.png`, dan daftarkan imej dalam `catalog.json`.

Imej Jun rujukan rasmi:
https://tk8.tekken-official.jp/images/character/jun/btn.png

Aset contoh menggunakan URL rasmi, tidak menyalin fail imej ke repositori. Ketika digunakan di laman awam, imej luaran tertakluk kepada akses dan kebenaran pemilik laman.
